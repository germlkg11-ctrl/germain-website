Why I Started Learning to Code

I decided to learn coding because I wanted to understand how websites, software, and modern technology are built. Rather than simply using technology every day, I wanted to learn how to create it.

Coding has taught me that every successful project begins by solving one small problem at a time. Each lesson strengthens my logical thinking, creativity, patience, and confidence.

What Motivates Me

I enjoy learning new skills that can make a positive difference in people's lives. Programming allows me to combine creativity with logical thinking while building practical solutions to everyday problems.

Every completed project reminds me that consistent effort leads to continuous improvement. Every challenge teaches me something valuable and helps me become a better developer.

My Learning Goals

  • Master HTML5 and modern CSS.
  • Create responsive and accessible websites.
  • Learn JavaScript for interactive web applications.
  • Study Python for backend development.
  • Understand databases and SQL.
  • Learn Git and GitHub professionally.
  • Explore Artificial Intelligence and Machine Learning.
  • Develop complete full-stack web applications.

Looking Toward the Future

This website represents the beginning of my programming journey. As I continue learning, I plan to expand my skills by creating increasingly advanced projects that demonstrate clean code, responsive design, accessibility, and professional development practices.

My long-term goal is to become a confident software developer capable of designing useful applications, solving meaningful problems, and continuing to learn throughout my career.

My Vision

I believe technology has the power to improve lives when it is used wisely. My goal is to continue building websites and applications that are useful, secure, accessible, and user-friendly while expanding my knowledge of Artificial Intelligence and software engineering.
