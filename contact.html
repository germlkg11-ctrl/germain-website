How This Form Works

At the moment, this form demonstrates the front-end portion of a website. HTML provides the structure of the form, while CSS controls its appearance and layout.

JavaScript adds behavior to the form. When the visitor submits the form, JavaScript prevents the page from reloading and displays a confirmation message instead.

In future lessons, a Python backend could receive the submitted information, process it securely, and either store it in a database or send it by email.

Example: id vs. name

For the Full Name field: 

id="visitor-name"
name="visitor-name"
  • id uniquely identifies the element on the webpage. It connects the label to the input field and can also be used by CSS or JavaScript.
  • name identifies the data that is sent to the backend when the form is submitted.

Although both values are the same in this project, they serve different purposes.
